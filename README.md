# Legion Construction Website

This is the official website for Legion Construction, showcasing our services, projects, and company information.

## Deployment

This website is configured for deployment on Vercel through GitHub.

## Project Structure

- `index.html` - Homepage
- `about.html` - About us page
- `services.html` - Overview of services
- `service-*.html` - Individual service pages
- `gallery.html` - Project gallery
- `contact.html` - Contact information
- `testimonials.html` - Client testimonials
- `assets/` - Contains all images, CSS, and JavaScript files

## Technology

This is a static HTML website using:
- HTML5
- CSS3
- JavaScript
